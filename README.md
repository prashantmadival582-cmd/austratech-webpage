# Austratech — Digital Solutions Website

A modern, responsive corporate website for Austratech, showcasing digital marketing, software development, and technology solutions for Australian businesses.

## About the Project

Austratech is a React.js website designed to present the company's services through a professional user interface, structured service pages, location-based content, and clear contact and project enquiry options.

The project focuses on responsive design, reusable React components, consistent branding, and SEO-friendly website architecture.

## Features

- Modern, responsive homepage and navigation.
- Company logo and consistent brand styling.
- Digital marketing and SEO service pages.
- Website and mobile application development services.
- Custom software development solutions.
- AI, data analytics, cloud, and DevOps services.
- UI/UX design and software testing services.
- Location-based service pages for Australian cities.
- Reusable service components and layouts.
- Contact page with project enquiry form.
- Calls to action for project enquiries.
- Breadcrumb-free page layout where configured.
- Responsive layouts for desktop, tablet, and mobile.
- SEO-focused page structure and internal linking.
- Service-specific metadata and structured data, where implemented.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- React Router DOM

## Getting Started

### Prerequisites

Install the following:

- Node.js (LTS recommended)
- npm
- Visual Studio Code (recommended)

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, typically:

   ```text
   http://localhost:5173/
   ```

## Build for Production

Run the following command to create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
